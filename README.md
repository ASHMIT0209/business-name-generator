# Business Name Generator

A web application that helps generate creative business names.

## Features

- Generate unique business name ideas
- Simple and intuitive user interface
- Fast name generation

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `script.js` - Application logic and functionality

## Usage

1. Open `index.html` in your web browser
2. Follow the on-screen instructions to generate business names
3. Browse through suggested names and find the perfect one for your business

## Getting Started

Simply open the `index.html` file in any modern web browser to start using the application. No installation or dependencies required.
